# Autonomous Warehouse Surveillance Robot

A ROS 2-based autonomous warehouse surveillance UGV.

## Technology Stack

- ROS 2 Jazzy
- Gazebo Harmonic
- Nav2 Autonomous Navigation
- GLIM LiDAR-Inertial SLAM
- LiDAR and IMU
- RGB Camera
- Autonomous Waypoint Patrol
- Obstacle Avoidance
- Web Dashboard
- Emergency Stop and Safety Monitoring

## Project Objective

Develop an autonomous warehouse surveillance robot
capable of mapping indoor warehouse environments,
navigating between operator-defined waypoints,
avoiding obstacles, and monitoring its surroundings.

## Current Development Stage

Migrated from the existing surveillance robotics
software architecture.

Warehouse-specific simulation, robot integration,
and navigation validation are pending.
